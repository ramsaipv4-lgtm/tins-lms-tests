# Day 1 quick learn: Pages and templates

Read this in ten minutes, then take the diagnostic. The full lesson is in the [deep dive](deepdive.md).

## 8-question diagnostic

1. Which command adds a new page called about?
2. Where does a page title live in the source?
3. Which template renders a single page by default?
4. Which template renders a list of pages?
5. Which key in the front matter hides a draft page?
6. Which folder holds partial templates?
7. Which command serves the site with live reload?
8. Which key sets the order of pages in a menu?

## Answer key

1. kettle new page about
2. front matter
3. single.html
4. list.html
5. draft
6. partials
7. kettle serve
8. weight
