# Day 0 quick learn: Setup and first build

Read this in ten minutes, then take the diagnostic. The full lesson is in the [deep dive](deepdive.md).

## 8-question diagnostic

1. Which command creates a new Kettle site folder?
2. Which file holds the site settings?
3. Which folder does a build write into?
4. Which command builds the site once?
5. Which flag prints the Kettle version?
6. Which folder holds the page sources?
7. Which command removes old build output?
8. Which file extension do page sources use?

## Answer key

1. kettle init
2. kettle.toml
3. public
4. kettle build
5. --version
6. pages
7. kettle clean
8. .md
