# Day 0 memory recall

Close your notes before you start.

## Exercise 1 — Recite the setup steps (5 min)

**What to do:** Write the three commands that create and build a new site, in order.

**The answer (check after):** kettle init demo-site, then cd demo-site, then kettle build.

## Exercise 2 — Draw the folder layout (5 min)

**What to do:** Sketch the folders that kettle init creates and label each one.

**The answer (check after):** pages for sources, themes for templates, public for build output.

## Exercise 3 — Explain the build in plain words (5 min)

**What to do:** Explain to a friend what kettle build does, in two sentences.

**The answer (check after):** It reads every page in pages, applies the theme, and writes HTML into public.
